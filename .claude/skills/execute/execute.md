# Step 3 — Execute Tasks

Work through the approved task list one by one.

## Progress tracking

Check off each task as it is completed:

```
1. [x] Set up base component — components/FeatureX.tsx
2. [x] Add API integration — lib/api.ts
3. [ ] Write unit tests — __tests__/FeatureX.test.ts
```

## Rules

- Follow the existing code style and conventions in the project
- Complete tasks in the approved order
- If something unexpected is discovered mid-execution, **pause and inform the user** before continuing
- Do not add scope beyond what was approved in the plan
